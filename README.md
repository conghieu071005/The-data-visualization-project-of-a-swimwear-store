# The data visualization project of a swimwear store
The data was collected from a retail swim accessories store over a three-year period and was visualized by me using Tableau version 2025.2. The objective is to gain a clear understanding of the store’s current operational performance and to identify management issues in order to optimize future profitability.

In this project, I will build four dashboards—Overview, Customer, Product, and Season—to provide insights ranging from a high-level overview to detailed analysis of the business operations.
